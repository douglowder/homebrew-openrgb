# Douglowder Openrgb

## How do I install these formulae?

`brew install douglowder/openrgb/<formula>`

Or `brew tap douglowder/openrgb` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "douglowder/openrgb"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
